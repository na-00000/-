# 📖 매일 국어 배움터 (양산희망학교 맞춤형 웹 접근성 학습 앱)

중도중복장애(발달장애 및 뇌성마비) 학생을 위해 설계된 **태블릿 PC 가로 화면(16:10 / 16:9) 최적화 5단계 매일 국어 학습 웹 애플리케이션**입니다.

---

## ✨ 주요 특징 및 접근성 설계

1. **뇌성마비·발달장애 맞춤형 터치 인터페이스**
   - 모든 버튼 크기 **최소 `76px × 76px` 이상**, 버튼 간 간격 **최소 `20px` 이상** 확보
   - 손떨림(Tremor)으로 인한 의도치 않은 이중 터치 방지 디바운스 적용
   - 눌림 상태가 직관적인 고대비 **3D 입체 버튼** 및 순수 CSS/SVG 애니메이션 적용
2. **한국어 청소년 남자아이 TTS 음성 안내 & Web Audio 효과음**
   - 별도 외부 음원 없이 Web Audio API 신시사이저(`DynamicsCompressor` 증폭)로 정답·오답·팡파르 효과음 구현
   - 한국어 청소년 남자아이 목소리 톤 자동 매칭 및 상단 `[👦 목소리 설정]` 모달 지원
3. **양산희망학교 식단 실시간 자동 반영**
   - 나이스(NEIS) 교육정보 개방 포털 및 [양산희망학교 식단 캘린더(mi=152211)](https://huimang-s.gne.go.kr/huimang-s/dv/dietView/selectDietCalendarView.do?mi=152211) 연동
   - 알레르기 번호 자동 제거 및 음식별 아이콘 자동 매칭
4. **초·중·종성·겹받침·이중모음 완벽 조합 대형 한글 자판**
   - 파란색 자음(1단) / 주황색 모음(2단) 색상 구획화
   - 다음 눌러야 할 글자 키 시각 하이라이트 및 `[💡 글자 힌트 듣기]` 음성 안내 지원

---

## 🚀 실행 화면 구성

- **학생용 학습 화면:** [`index.html`](./index.html)
  - `1단계` 오늘 날짜 선택 → `2단계` 오늘의 날씨 → `3단계` 나의 기분 → `4단계` 양산희망학교 오늘의 급식 → `5단계` 오늘의 한 문장 따라 쓰기
- **교사용 관리자 화면:** [`admin.html`](./admin.html)
  - 날짜별 학생 수행 기록 달력 조회, 양산희망학교 식단 동기화/편집, 오늘의 문장 데이터베이스 관리

## 📂 폴더 구조

```text
├── index.html              # [학생용] 5단계 매일 과제 학습 UI
├── admin.html              # [교사용] 데이터 업데이트 및 학생 기록 조회 UI
├── css/
│   ├── style.css           # 태블릿 가로 화면 원스크린 레이아웃 & 3D 버튼 스타일
│   ├── keyboard.css        # 뇌성마비 맞춤형 2단 대형 한글 자판 스타일
│   └── assets/
│       ├── weather.css     # 순수 CSS/SVG 날씨 애니메이션 (해, 구름, 비, 눈)
│       ├── emotion.css     # 순수 CSS/SVG 감정 캐릭터 애니메이션 (기쁨, 슬픔, 화남, 신남)
│       └── components.css  # 3D 버튼, 오답 쉐이크, 폭죽 파티클 등 접근성 자산
└── js/
    ├── app.js              # 5단계 학습 흐름 제어 & 양산희망학교 식단 자동 연동
    ├── keyboard.js         # 한글 자모 조합/분해 오토마타 & 오답 검증 엔진
    ├── audio.js            # Web Audio 신시사이저 & 청소년 남자아이 TTS 엔진
    └── admin.js            # 교사용 식단/문장 관리 & 일일 학습 기록 뷰어
```
